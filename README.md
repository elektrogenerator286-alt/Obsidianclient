# Visual HUD (Fabric, Minecraft 1.21.11)

Серый полупрозрачный HUD с белой подсветкой и частицами.

- FPS и пинг: сверху слева
- Эффекты зелий: сверху справа, у каждого иконка зелья с цветом эффекта (ванильные скрыты)
- Кулдауны: маленькая панель сразу под эффектами (только когда есть кулдаун)
- Хотбар: снизу по центру (замена ванильного)
- Предмет во второй руке: круг слева от хотбара (только если предмет есть)
- Надетая броня: иконки каждой надетой вещи и её прочность справа от хотбара (ванильная шкала брони скрыта)

## Сборка
1. Установите JDK 21.
2. В папке проекта: `gradle wrapper` (один раз), затем `./gradlew build`
3. Готовый мод: `build/libs/obsidianclient-1.0.0.jar` положите в `mods/` вместе с Fabric API.

Для запуска из IDE: `./gradlew runClient`.

## Настройка внешнего вида
Всё в `src/main/java/visualhud/Ui.java`:
- `PANEL`, `TEXT`, `TEXT_DIM`: цвета
- `TEXT_SCALE`: размер текста (0.8 по умолчанию)
- alpha в `softPanel` и `softCircle`: прозрачность панелей и краёв
- частицы: `Emitter.java`

## Меню (Right Shift)
Маленькое меню в том же стиле. Открывается и закрывается правым Shift (или Esc), появляется плавно: проявление, лёгкое «вырастание» на месте и вспышка подсветки.

- клик по пункту: включить / выключить
- правый клик по пункту (или `+` / `-`): раскрыть настройки
- настройки: переключатель (клик), ползунок (тянуть мышью), выбор из списка (клик вперёд, правый клик назад)
- состояние сохраняется в `config/visualhud.json`

Пунктов пока нет, меню показывает «Пока пусто». Чтобы добавить пункт, зарегистрируйте его в `Features.init()` (пример в комментарии там же), а в коде мода читайте значения через `Features.enabled("Название")` или напрямую из объектов `Setting`.
Клавишу меняет константа `MENU_KEY` в `VisualHudClient.java`.
