# Pulse HUD (Fabric, Minecraft 1.21.11)

Клиентский мод: тёмные скруглённые панели с белой обводкой и белыми частицами, которые разлетаются от краёв.

| Панель | Где |
|---|---|
| FPS и пинг | сверху слева |
| Эффекты зелий (иконка, название, уровень, время) | сверху справа |
| Кулдауны предметов из инвентаря (иконка + полоска) | справа, под эффектами |
| Хотбар (скруглённая «пилюля», разделители, подсветка выбранного слота) | снизу по центру |
| Предмет во второй руке (круг, только если он есть) | слева от хотбара |
| Прочность брони (иконка + процент) | справа от хотбара |

Клавиша **]** (по умолчанию, меняется в Управлении → Pulse HUD) включает и выключает мод. Когда мод выключен, возвращается обычный HUD.

## Сборка

**Без установки Java:** каждый пуш в `main` собирает jar на GitHub. Откройте вкладку **Actions**, выберите последний запуск и скачайте артефакт `pulsehud-jar`. Если запушить тег вида `v1.0.0`, jar появится ещё и в разделе **Releases**.

Или соберите сами:

Нужна **Java 21** (для 1.21.11 подходит именно 21) и интернет (Gradle скачает Minecraft и Fabric).

```
./gradlew build          # Linux / macOS
gradlew.bat build        # Windows
```

Готовый мод: `build/libs/pulsehud-1.0.0.jar`. Положите его в папку `mods` вместе с **Fabric API** (Fabric Loader 0.18+).

Для запуска из среды разработки: `./gradlew runClient`.

## Где что менять

* `PulseHudClient.java` — регистрация HUD и скрытие ванильного хотбара и иконок эффектов (через Fabric API, без mixin).
* `Hud.java` — раскладка и содержимое всех панелей.
* `Particles.java` — частицы (скорость, размер, время жизни, сколько их).
* `Gfx.java` — вся отрисовка текстур. Если после обновления Minecraft сломаются сигнатуры `DrawContext`, править нужно только его.
* `src/main/resources/assets/pulsehud/textures/gui/*.png` — текстуры панели, круга, подсветки слота и частицы. Их можно заменить на свои (панель 64×64 с радиусом углов 16 px, круг 32×32, подсветка 32×32, частица 16×16). Файлы `.png.mcmeta` рядом включают плавное сглаживание, не удаляйте их.
* `tools/make_textures.py` — скрипт, которым текстуры сгенерированы (цвет обводки, толщина, прозрачность фона).

## Если сборка ругается

Мод писался без возможности скомпилировать его в той среде, поэтому мелкие расхождения с названиями методов (маппинги Yarn 1.21.11) возможны. Пришлите текст ошибки, и я поправлю.
